導入動畫

等待偵測 Blender 路徑

摟腰與摸頭會讓兩人靠近，管理員雙手追蹤對方腰部或頭部；大幅移動的動畫可能超出手臂範圍。

讀取本模組轉換或另存的動畫 JSON；校準設定請在小鍵盤插槽讀取。相同動畫 ID 會更新原項目。

FBX 會自動取得互動角色的 Mesh.bindposes，再用 Blender 背景重定向。支援 Mixamo 與本次 Chocolate 骨架；其他骨架會回報缺少對應。

FBX / VMD 需本機 Blender；VMD 使用內建骨架，只匯入動作。

瀏覽動畫

拖曳項目調整順序。刪除動畫後，引用它的插槽保留並標示缺失。

    使用前請停用 BEM 相機模組並重啟遊戲。僅關閉第一人稱視角可能仍會佔用入口，造成連接失敗。

    尚未播放

    作用於主控。腳以播放前的接觸點為支點；膝以起始姿勢為支點。跳躍或抬腳動畫請選不固定。選擇後隨校準設定保存至互動預設。

    尚未準備

    匯出路徑：尚未匯出

    播放動畫：播放所選動畫，讓支援的骨架設定即時反映到遊戲內容。

    停止播放：停止動畫並還原角色狀態，保留已調整的參數。

    準備匯出：記錄目前主控、互動角色、動畫與骨架參數，建立可匯出或套用至小鍵盤槽位的設定快照；修改設定後需重新準備。

    另存參數設定：將已準備的設定保存為 JSON 檔案，完整路徑顯示在上方。檔案引用動畫 ID，不包含動畫本身。

    骨架設定

    主控／互動角色的全部骨架參數

    先更新隊伍並套用互動角色，再更新全部骨架。

    FBX 人物根節點：XYZ 以管理員為基準（X 左右、Y 上下、Z 前後，單位 cm），換位置或朝向後重新播放會保留雙人佈置；調整主控 root 會帶動整個佈置。其他骨架：局部位移（cm）、局部旋轉（度）、相對縮放（倍）。數值疊加在動畫上；人物根節點控制整個模型。縮放與位移可能改變人物比例；尚未提供完整 IK 或碰撞修正。

    外部模型調整

    BEM 與 EFMI 可以同時啟動。BEM 請選擇「XInput 自啟動」；請停用 BEM 第一人稱／相機模組並重啟遊戲。

    只修改獨立 BEM 橋接檔。調整後寫入橋接，再回遊戲按重載鍵套用；停用不會重設 EFMI 已保存的值。可辨識頂點／索引的網格可做幾何變形；不會新增骨架關節。
